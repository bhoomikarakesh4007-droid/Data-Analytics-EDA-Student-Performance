# Exploratory Data Analysis on Student Academic Performance

## Aim
To perform Exploratory Data Analysis (EDA) on a student academic performance dataset using statistical measures and data visualization techniques.

## Description
This project analyzes student academic performance using Python. The dataset includes study hours, attendance percentage, internal marks, and final examination scores. Statistical analysis and visualization techniques are used to identify patterns, distributions, outliers, and relationships among the variables.

## Tools Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Analysis Performed
- Dataset creation and inspection
- Missing value and duplicate checking
- Mean, median, mode, variance, and standard deviation calculation
- Histogram visualization
- Boxplot and outlier detection using the IQR method
- Scatter plot analysis
- Correlation analysis and heatmap visualization

## Results
The dataset contains 18 students with no missing or duplicate values. The average final score is 62. One outlier was identified with a final score of 22. Attendance showed a strong positive correlation with final scores, followed by internal marks. Study hours also showed a positive correlation with academic performance.

## Conclusion
Exploratory Data Analysis helped understand the dataset, identify outliers, visualize score distributions, and analyze relationships between academic variables. The analysis indicates that attendance and study habits are associated with student academic performance.
